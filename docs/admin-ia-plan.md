# 관리자 IA 통합 설계

**버전:** v0.1 (초안) · **작성일:** 2026-09-02 · **상태:** 검토 대기

## 문제

사이드바가 12개로 불었고, **전역 vs 캠페인 스코프**가 섞여 있다.

```
대시보드 · 캠페인 · 퍼널 흐름도 · 상품 관리 · 쿠폰 · CRM 고객 ·
여정 지도 · 자동 메시지 · 브로드캐스트 · 결제/주문 · 광고 성과 · 연동 설정
```

구체적 냄새:
- **같은 걸 3번 본다** — `/flow`(xyflow 지도), `/journey`(퍼널+문자 타임라인),
  캠페인 허브의 "퍼널 흐름" 카드가 전부 "퍼널 모양"을 보여줌
- **전역/캠페인 혼란** — "자동 메시지"는 전역+캠페인오버라이드, "흐름도"는 전역 뷰인데
  캠페인마다 다르니 전역 뷰가 사실 의미 없음
- **거의 안 쓰는데 상단에** — 연동 설정, 광고 성과
- 12개 평면 나열, 그룹 없음

## 원칙 (클릭퍼널스 멘탈모델)

> **대부분은 "캠페인 안"에 있어야 한다. 상단 = 캠페인을 가로지르는 것만.**

- 캠페인 하나 = 그 퍼널의 단계·페이지·자동화·지표·A/B 전부
- 상단 = 연락처(전 캠페인 공통), 상품 카탈로그, 전사 매출, 계정 설정

## 새 IA

### 상단 (12 → 6)

| 메뉴 | 내용 | 흡수 |
|---|---|---|
| **📊 오늘** | 전사 요약 + "지금 처리할 것" (아래 §대시보드) | 기존 대시보드 |
| **🎯 캠페인** | 목록 → 캠페인 = 탭 5개 (아래 §캠페인) | flow, journey 흡수 |
| **👥 고객** | 연락처(CRM) + 여정 + 브로드캐스트 + 전역 자동 메시지 | crm, broadcasts, automation(전역) |
| **📦 상품** | 상품 카탈로그 · 쿠폰(탭) | products, coupons |
| **💳 매출** | 주문 · 구독 · 광고 성과(탭) | orders, analytics |
| **⚙️ 설정** | 연동 키 · 문자 발신 · 도메인 · 픽셀 기본값 | settings |

### 캠페인 안 (탭)

```
◀ 캠페인 목록
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[개요]  [퍼널]  [자동 메시지]  [지표]  [설정]
```

| 탭 | 내용 | 대체 |
|---|---|---|
| **개요** | 요약 스탯 + **설정 체크리스트** + A/B 상태 + 빠른 링크 | 현재 허브 |
| **퍼널** | 단계 빌더(순서/추가/빼기) + 각 단계 편집·미리보기 + **시각 흐름도 토글**(노드+연결) + 시스템 전환(문자/웹훅) 점선 | 허브 "퍼널 흐름" 카드 + `/flow` + `/journey` 를 **하나로** |
| **자동 메시지** | 이 캠페인에 적용되는 자동화 (전역 상속 + "이 캠페인만 수정") | `/automation?campaign=` |
| **지표** | 단계별 이탈·전환율·AOV·EPC·ROAS + A/B 결과 상세 + 일자별 | 허브 "퍼널 지표" 카드 확장 |
| **설정** | 영상·캘린더·단톡방·카운트다운·픽셀·상품매핑·퍼널종류·회차 | 현재 `/campaigns/[id]/settings` |

빌더는 지금처럼 풀스크린(사이드바 밖), "퍼널" 탭에서 진입.

## 없어지는/합쳐지는 것

| 지금 | 이후 |
|---|---|
| `/admin/flow` (전역 흐름도) | 삭제 — 캠페인 "퍼널" 탭의 시각 흐름도로 |
| `/admin/journey` (여정 지도) | 삭제 — 같은 탭의 "타임라인 보기" 토글 |
| `/admin/automation` (전역) | "고객 > 자동 메시지 > 전역 기본" 으로 이동 (라우트 유지, 메뉴만) |
| `/admin/broadcasts` | "고객 > 브로드캐스트" 탭 |
| `/admin/coupons` | "상품 > 쿠폰" 탭 |
| `/admin/orders` `/admin/analytics` | "매출" 아래 탭 |

**라우트는 최대한 유지**하고 **네비게이션과 탭만 재배치** → 리스크 최소. `/flow` `/journey` 만 실제 삭제(내용은 "퍼널" 탭에 재구현).

## 대시보드("오늘") 재설계

브런슨: *대시보드는 숫자판이 아니라 "오늘 뭐 해야 하는지"다.*

```
┌─ 지금 처리할 것 ─────────────────────────┐
│ • 발행 대기 캠페인 2개  →                  │
│ • 검토 안 한 자동 메시지 5개  →            │
│ • 결제 실패 구독 1건  →                    │
│ • 이탈 카트 3명 (자동 문자 나감)           │
└──────────────────────────────────────────┘

이번 주 매출  ₩1,240,000  ▲ 지난주 대비 +18%
신규 신청 47  ·  구매 12  ·  상담 예약 5

캠페인별  (미니 지표 카드, 클릭 → 개요 탭)
```

## 실행 단계

| Phase | 범위 | 리스크 |
|---|---|---|
| **A. 네비 재편** | 사이드바 6개 그룹 + 캠페인 탭바 컴포넌트. 라우트는 유지, 링크·레이아웃만 | 낮음 |
| **B. 캠페인 탭 통합** | 허브를 "개요/지표"로 쪼개고, "퍼널" 탭 신설(빌더 리스트 + 시각 흐름도) | 중 |
| **C. flow/journey 폐기** | `/flow` `/journey` 내용을 "퍼널" 탭에 재구현 후 라우트 제거 | 중 |
| **D. 대시보드 "오늘"** | 액션 큐 + 주간 매출 + 캠페인 미니카드 | 낮음 |
| **E. 하위 탭** | 상품/쿠폰, 매출/주문/광고, 고객/브로드캐스트/자동메시지 탭화 | 낮음 |

추천: **A → D → E → B → C** (A·D·E 는 빠르고 안전, B·C 는 flow 재구현이라 뒤에)

## 열린 질문

1. 사이드바 유지 vs 상단 탭바로 전환. → 사이드바 유지(그룹 헤더 추가)가 안전.
2. "퍼널" 탭의 시각 흐름도를 지금 `/flow`(xyflow 라이브 iframe) 그대로 가져올지,
   더 가벼운 SVG 다이어그램으로 새로 그릴지. → 라이브 iframe이 가치 있음, 재사용.
3. 전역 자동 메시지 편집을 "고객" 아래 둘지 "설정" 아래 둘지. → "고객" (메시징은 고객 관리).
4. `/journey` 타임라인을 살릴지 완전히 버릴지. → "퍼널" 탭 토글로 살림(읽기 전용).
